# 教學教材影像標記指南

本指南適用於教材、課堂投影片、練習題、圖表與手寫筆記的影像分析資料集。

## 標記類別

- `textbook_page`：教材或講義頁面
- `worksheet`：練習題、作業或學習單
- `diagram`：圖表、流程圖、幾何圖形與示意圖
- `slide`：課堂投影片
- `handwritten_note`：手寫筆記或白板內容
- `formula`：數學式、化學式或程式碼區塊
- `unknown`：內容不足或無法安全判斷

## 標記規則

## 1. 標記框 (Bounding Box) 規範
*   **完整框選**：如果教材頁、題目或圖表在畫面中完整可見，請框住整個內容區塊。
*   Bounding box 必須貼近實際文字、圖表或教材區塊，不要包含過多背景。
*   圖片模糊、反光、遮擋或文字無法讀取時，標記為 `unknown`，不要自行推測。
*   同一頁有多個獨立題目或圖表時，分別標記，保留閱讀順序。
*   手寫內容與印刷內容分開標記，方便後續 OCR 與課後回饋。
*   資料集要涵蓋手機拍攝、掃描、不同光線、傾斜、裁切與不同字體。
*   不收集不必要的姓名、電話、地址或其他學員個資；必要時先遮罩。

## 驗收清單

*   [ ] 每個類別都有清楚的正例與 `unknown` 負例。
*   [ ] OCR 文字與 bounding box 經人工抽樣確認。
*   [ ] 圖表、公式、手寫筆記不會被全部誤判成一般文字。
*   [ ] 模型輸出包含 confidence，低信心結果能回到人工／老師檢查。
*   [ ] ONNX 模型可由 `public/models/` 受控載入。
*   [ ] 測試圖片不含未授權的學員個資或正式課程機密。

## 2. 角度多樣性 (Perspective)
*   **多面拍攝**：正面、斜拍、局部裁切與不同距離都要涵蓋，保留文字閱讀順序。
*   **模擬教學場景**：教材可能放在書桌、白板、課堂投影或學員手中，應涵蓋真實教學環境但避免收集不必要的個資。

## 3. 背景與環境 (Background)
*   **真實場景**：涵蓋書桌、教室、白板、投影畫面與掃描文件等情境。
*   **陰影與反光**：標記時不要把背景陰影納入教材區塊；若反光造成文字無法辨識，標記為 `unknown`。

## 4. 常見問題 (FAQ)
*   **Q: 一張圖片有多個題目怎麼辦？**
    *   A: 各自標記並保留由上到下、由左到右的閱讀順序。
*   **Q: 公式或手寫內容看不清楚怎麼辦？**
    *   A: 不要猜測，標記為 `unknown` 或降低 confidence，交由學員／老師確認。

## 5. Roboflow 推介設定
*   **Dataset Versioning**：不要在原本的資料集上亂改，每次匯出前產出一個新版本 (e.g. `v1`, `v2`)。
*   **Preprocessing**：
    *   Auto-Orient: On
    *   Resize: Stretch to 640x640 (需與 YOLO `imgsz` 參數一致)
*   **Augmentation**：
    *   Horizontal Flip (左右翻轉)
    *   Brightness (亮度調整 +/- 25%)
    *   Blur (模糊處理，模擬相機微晃)
