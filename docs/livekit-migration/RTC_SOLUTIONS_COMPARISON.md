# RTC 解決方案完整對比

## 全景對比表

| 維度 | **Agora** (現況) | **LiveKit 自建** | **LiveKit Cloud** | **Twilio** | **Amazon Chime SDK** | **Jitsi (開源)** |
|---|---|---|---|---|---|---|
| **部署方式** | SaaS (第三方) | 自建 EC2 | SaaS (LiveKit 代管) | SaaS | SaaS | 自建或開源 |
| **月成本 (10房間)** | ~$50 | $40-75 | ~$120 | ~$150 | ~$100 | $0-40 |
| **月成本 (50堂課/天)** | $559 | $75-150 | ~$300 | ~$500 | ~$250 | $50-200 |
| **月成本 (150堂課/天)** | $1500+ | $150-300 | ~$600 | $1200+ | ~$500 | $150-600 |

## 詳細評分

### 1. **Agora**（現況主服務商）

```
特性                   評分    備註
────────────────────────────────────────────
定價模式               ⭐⭐⭐ 按分鐘，無上限（超用超費）
功能完整性             ⭐⭐⭐⭐⭐ 企業級全套（RTM + 白板）
開發友善度             ⭐⭐⭐⭐⭐ SDK 文檔齊全，demo 多
可靠性 & SLA          ⭐⭐⭐⭐⭐ 全球 CDN，99.9% uptime
運維成本               ⭐⭐⭐⭐⭐ 完全託管，0 運維
擴縮性                 ⭐⭐⭐⭐⭐ 自動擴縮，無需考慮容量
身分驗證               ⭐⭐ ⚠️ 原本無（硬編碼憑證）
時長紀錄精準度         ⭐⭐ ⚠️ 依 Agora 帳單，可能延遲
依賴鎖定               ⚠️ 高    SDK 緊耦合，遷移成本大
```

**適用場景**
- ✅ 快速上線，不想自建
- ✅ 全球分佈式用戶
- ✅ 需要 RTM + 白板一站式
- ❌ 對成本敏感的 B2C
- ❌ 需要完整時長紀錄

**風險**
- 👤 單點依賴（Agora 掛 = 全站掛）
- 💰 隨著規模增長，費用線性上升（無成本封頂）
- 🔐 信令層無身分驗證

---

### 2. **LiveKit 自建 (EC2)**

```
特性                   評分    備註
────────────────────────────────────────────
定價模式               ⭐⭐⭐⭐ 固定成本（預留執行個體）
功能完整性             ⭐⭐⭐⭐ 媒體轉發完整，信令自主
開發友善度             ⭐⭐⭐ 文檔好，SDK 活躍
可靠性 & SLA          ⭐⭐⭐ 自建 = 自己負責
運維成本               ⭐⭐ ⚠️ 需要 OS patch + 監控
擴縮性                 ⭐⭐⭐ 手動（ECS Fargate 可自動）
身分驗證               ⭐⭐⭐⭐⭐ withAuth + 角色檢查
時長紀錄精準度         ⭐⭐⭐⭐⭐ Webhook server-truth
依賴鎖定               ✅ 低    開源，可自主掌控
```

**適用場景**
- ✅ 規模 50+ 堂課/天時成本優勢明顯
- ✅ 需要精準時長紀錄（薪資結算）
- ✅ 對 SLA 要求可控（自建 SLA）
- ✅ 地理位置能自主選擇（Tokyo, Singapore）
- ❌ MVP 階段（過度設計）
- ❌ 全球多地區（需多 region 部署）

**風險**
- 🔧 運維負擔（監控、OS patch）
- 📈 規模達 150+ 堂課需多節點（複雜度 ⬆）
- 🔐 安全責任轉到自己

### 3. **LiveKit Cloud**（由 LiveKit 官方代管）

```
特性                   評分    備註
────────────────────────────────────────────
定價模式               ⭐⭐⭐⭐ 按使用量計費（可預估）
功能完整性             ⭐⭐⭐⭐ 同自建 LiveKit
開發友善度             ⭐⭐⭐⭐ 同自建
可靠性 & SLA          ⭐⭐⭐⭐ LiveKit 官方保證
運維成本               ⭐⭐⭐⭐⭐ 完全託管
擴縮性                 ⭐⭐⭐⭐⭐ 自動擴縮
身分驗證               ⭐⭐⭐⭐⭐ 同自建
時長紀錄精準度         ⭐⭐⭐⭐⭐ 同自建
依賴鎖定               ⭐⭐⭐ 中等   還是 LiveKit 代管
```

**適用場景**
- ✅ 不想自建，又要 LiveKit 特性
- ✅ 中等規模（50-200 堂課/天）
- ✅ 全球分佈式用戶（官方 multi-region）

- ❌ 規模超大（自建多節點 vs 按量計費）

**成本範例**
```
50 堂課/天：
  ├─ 2GB 頻寬 × 30 天 × $0.15/GB = ~$90
  ├─ 計算成本 = ~$150-200
  └─ 總計 ~$240-290/月
```

## 決策矩陣

```
選擇 Agora：
  ✅ 快速上線，無須自建
  ✅ 全球 CDN，穩定性最高
  ❌ 規模越大越貴（無封頂）
  ❌ 單點依賴風險

選擇 LiveKit 自建：
  ✅ 規模達 50+ 堂課時最便宜
  ✅ 精準時長紀錄（Webhook）
  ✅ 自主時長記錄、身分驗證
  ❌ MVP 過度設計
  ❌ 需要自建運維
  ➡️ 推薦：50+ 堂課/天

選擇 LiveKit Cloud：
  ✅ LiveKit 功能 + SaaS 便利
  ✅ 自動擴縮，無運維
  ❌ 比自建貴 3 倍
  ➡️ 推薦：中等規模 50-200 堂課

選擇 Twilio：
  ✅ 企業級功能 + 多通訊整合
  ❌ 成本最高（Agora 的 1-3 倍）
  ➡️ 推薦：已用 Twilio 全套服務

選擇 Jitsi 自建：
  ✅ 開源免費，隱私最高
  ❌ 運維複雜（技術門檻高）
  ➡️ 推薦：極度成本敏感 + 技術實力強

選擇 Chime SDK：
  ✅ AWS 整合，企業內部用
  ❌ B2C 市場陌生
  ➡️ 推薦：AWS-first 企業
```

## 最終建議

### MVP（10 組課）
```
推薦順序：
  1️⃣ Agora（快速上線，成本可接受）
  2️⃣ LiveKit 自建 Lightsail（月省 $10，有運維）
  3️⃣ Jitsi 自建（極低成本，技術難度高）
```

### 中期（50+ 堂課/天）
```
推薦順序：
  1️⃣ LiveKit 自建 EC2（成本 $100/月 vs Agora $559/月，省 82%）
  2️⃣ LiveKit Cloud（無運維，成本 $300/月）
  3️⃣ 如無特殊需求，不建議繼續用 Agora
```

### 大規模（150+ 堂課/天）
```
推薦順序：
  1️⃣ LiveKit 自建 ECS Fargate 多節點（$200-400/月）
  2️⃣ LiveKit Cloud + multi-region（$600+/月）
  3️⃣ Chime SDK（$630/月，AWS 生態優先）
```
