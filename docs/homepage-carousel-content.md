# 首頁輪播圖內容規格（平台功能盤點 → 出圖用）

版本日期：2026-09-19
用途：依平台實際功能產出首頁 Hero 輪播圖（`/carousel` 後台上傳，首頁 `app/ClientHomePage.tsx` 顯示）
內容來源：`docs/MVP.md`、`docs/JVTutorCorner_使用者手冊.md`、實際路由與 API

---

## 1. 技術規格（出圖前必讀）

| 項目 | 規格 | 依據 |
|---|---|---|
| 尺寸比例 | **1200 × 628 px**（可出 2 倍 2400 × 1256） | `app/globals.css` `.carousel-slide { aspect-ratio: 1200/628 }` |
| 裁切方式 | `object-fit: cover`，左右／上下可能被裁 | `components/Carousel.tsx` |
| 安全區 | 文字與 Logo 內縮 **至少 80px**，重點置中偏左 | cover 裁切保險 |
| 格式 | JPG（上傳時一律轉 `image/jpeg`） | `app/carousel/page.tsx` `compressImage()` |
| 檔案大小 | 壓縮後 ≤ 5MB，長邊自動縮到 1920px | 同上 `MAX_DIMENSION = 1920` |
| 張數建議 | 5–6 張（每 4 秒自動切換，一輪約 24 秒） | `Carousel` 預設 `intervalMs = 4000` |
| 檔名 | **檔名會直接變成 alt 文字**，請用有意義的中文或英文檔名 | `formData.append('alt', file.name)` |
| 圓角/陰影 | 前端已加 16px 圓角與陰影，圖內不要自己畫圓角 | `.hero-premium-carousel .carousel` |

> **多語系注意**：輪播圖是「全站共用一組」，不會隨 zh-TW / zh-CN / en 切換。
> 建議 **圖內文字最少化**（主標 + 一句副標），或做成視覺為主、文字為輔，避免英文使用者看到滿版中文。

### 底圖配色（與首頁 Hero 一致）

| 用途 | 色碼 |
|---|---|
| Hero 深底（圖片建議同色系） | `#0F172A` → `#1E293B` 漸層 |
| 品牌主色（按鈕、重點字） | `#8B5CF6` / `#7C3AED` |
| 輔助光暈 | `rgba(37, 99, 235, 0.15)` 藍、`rgba(99, 102, 241, 0.1)` 靛 |
| 淺底版本 | 背景 `#F6F0FB`、淡紫 `#EBDCFD`、文字 `#111827` |

## 2. 平台功能盤點（分組結果）

| 群組 | 實際功能 | 主要入口 | 可否對外宣傳 |
|---|---|---|---|
| A. 找老師找課程 | 師資列表／個人頁、課程列表／詳情、科目/語言/老師/模式篩選、課程與師資皆需後台審核 | `/teachers`、`/courses` | ✅ 可 |
| B. 個人化推薦 | 新手問卷（註冊後／訪客閒置觸發）、混合權重推薦引擎、行為追蹤 | 首頁、`/api/recommendations` | ✅ 可 |
| C. 線上教室 | 麥克風/攝影機/喇叭檢測、等候室雙方就緒同步、音視訊、互動白板、PDF 教材同步翻頁、上課倒數 | `/classroom/wait`、`/classroom/room` | ✅ 可（白板/PDF 同步壓測中，文案別寫「零延遲」） |
| D. 彈性付費 | 訂閱方案（Basic/Pro/Elite）＋點數包並行、折扣、App 方案扣抵、Stripe / PayPal / LINE Pay / 綠界 | `/pricing`、`/settings/pricing` | ✅ 可（LINE Pay、ECPay 狀態 ⚠️，建議只寫「多元金流」） |
| E. 點數暫存保障 | 報名扣點進 Escrow 暫存、完課釋放給老師、取消退回學生、爭議由管理員裁決 | `lib/pointsEscrow.ts`、`/teacher-escrow` | ✅ 可（最強差異化賣點） |
| F. 排課與提醒 | 行事曆、開課前 3 小時 Email 提醒、每日報表排程 | `/calendar`、`/calendar/reminders` | ✅ 可 |
| G. 老師端經營 | 課程建立/編輯/上下架送審、學生名單與剩餘堂數、收益與暫存點數看板 | `/teacher_courses`、`/courses_manage`、`/teacher-escrow` | ✅ 可（招募老師用） |
| H. 企業方案 B2B | 企業註冊、部門樹、席次（License）指派、CSV 批次匯入（單次 ≤200 筆）、帳務與稽核日誌 | `/admin/organizations` | ✅ 可（帳務自動化尚未完成，別提「自動計費」） |

| J. 多語系與 RWD | zh-TW / zh-CN / en、行動版選單 | 全站 | ⭕ 當配角，不單獨做一張 |

## 3. 輪播圖腳本（核心 6 張，依建議順序）

### 圖 1 — 品牌總覽
- **檔名**：`01-一站式線上家教.jpg`
- **主標**：從找老師到上課，一站完成
- **副標**：選課 → 報名 → 進教室 → 完課結算，全流程線上閉環
- **視覺**：深色底（`#0F172A`），四步驟流程線，節點用紫色圓點發光
- **AI 生圖 prompt**：`深藍近黑漸層背景的現代教育平台橫幅，畫面中央一條水平四節點流程線，節點發出紫色光暈，右側是簡化的線上課程介面示意，扁平插畫風格，乾淨、留白多、無文字，1200x628`

### 圖 2 — 師資與課程
- **檔名**：`02-嚴選師資與課程.jpg`
- **主標**：嚴選師資，課課審核
- **副標**：可依科目、語言、授課模式篩選；老師檔案與課程上架皆經後台審核
- **視覺**：師資卡片牆（3–4 張頭像卡）＋ 篩選側欄示意，右上角「已審核」徽章
- **AI 生圖 prompt**：`線上教育平台的師資列表介面示意圖，三張並排的老師卡片含圓形頭像與評分星等，左側有科目與語言篩選器，紫色主色 #8B5CF6，白底淺紫 #F6F0FB，扁平 UI 插畫，無文字，1200x628`

### 圖 3 — 個人化推薦
- **檔名**：`03-個人化課程推薦.jpg`
- **主標**：一份問卷，課程自己找上門
- **副標**：新手問卷 + 學習行為分析，推薦真正適合你的課
- **視覺**：左側問卷勾選卡，右側三張推薦課程卡由虛線連出
- **AI 生圖 prompt**：`個人化推薦概念插畫，左邊一張問卷卡片有勾選項目，右邊三張課程推薦卡片，之間用發光的紫色虛線連接，深色背景，扁平現代風格，無文字，1200x628`

### 圖 4 — 線上互動教室（**最重要，建議放第一或第二張**）
- **檔名**：`04-線上互動教室.jpg`
- **主標**：教室不只是視訊
- **副標**：設備檢測、雙方就緒同步、互動白板、PDF 教材即時翻頁
- **視覺**：教室介面示意——主視訊窗 + 小窗、右側白板筆跡、下方 PDF 翻頁列、角落倒數計時
- **AI 生圖 prompt**：`線上教室介面示意圖，左側大視訊畫面與右上角小視訊窗，右側白色互動白板上有手寫筆跡與圖形，底部 PDF 教材頁面縮圖列，右上角倒數計時器，深色 UI，紫色與藍色點綴，扁平 UI 插畫，無文字，1200x628`

### 圖 5 — 彈性付費
- **檔名**：`05-方案與點數雙軌.jpg`
- **主標**：方案訂閱、點數單買，都可以
- **副標**：月費方案與點數包並行，支援多元線上金流與折扣設定
- **視覺**：左右並列兩張價目卡（訂閱 / 點數包），下方一排金流圖示剪影
- **AI 生圖 prompt**：`兩張並排的定價卡片，左卡為訂閱方案右卡為點數包，卡片下方一排通用支付卡與錢包圖示剪影，淺紫背景 #F6F0FB，紫色重點色，扁平 UI 插畫，無品牌 logo，無文字，1200x628`
- ⚠️ 圖內**不要**放 Stripe / PayPal / LINE Pay 官方 Logo（商標授權風險），用通用支付圖示。

### 圖 6 — 點數暫存保障（差異化賣點）
- **檔名**：`06-點數暫存保障.jpg`
- **主標**：完課才付款給老師
- **副標**：報名先扣點暫存，完課釋放、取消退回，爭議由平台裁決
- **視覺**：三階段流程——「學生扣點 → 平台暫存（盾牌鎖頭）→ 老師收款」
- **AI 生圖 prompt**：`三階段資金保障流程插畫，左為學生圖示，中間為帶鎖頭的盾牌代表款項暫存，右為老師圖示，箭頭從左到右流動並發出紫色光，深色背景，扁平信任感設計，無文字，1200x628`

## 5. 上架步驟

1. 以管理員帳號登入 → 進入 `/carousel`。
2. 依序上傳圖 1 ~ 圖 6（**上傳順序即顯示順序**，`order` 依上傳當下的張數遞增）。
3. 用列表的上移／下移調整順序（會打 `PATCH /api/carousel` 更新 `order`）。
4. 回首頁 `/` 確認：首頁為 `force-dynamic`，重新整理即可看到新圖，無需重新部署。
5. 若後台沒有任何圖片，首頁會 fallback 成三張純文字輪播（`carousel_slide1~3`，見 `locales/*/common.json`）。
